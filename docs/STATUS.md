  실기기로 확인해 줄 수 있으면 `npm run dev` 후 나오는 주소를 폰에서 열고
  좌상단 fps를 알려 달라. 답이 없으면 다음 바퀴는 **`World.step()` 처리 시간**을
  재는 쪽으로 진행한다 — 그것만으로 60fps를 주장하지는 않고,
  "시뮬레이션은 예산 안에 든다"까지만 말한다.
